# Agentbox (Reapit Sales)

> Australian real estate CRM and sales platform for residential sales agencies across Australia and New Zealand, rebranded Reapit Sales after acquisition by the UK proptech group Reapit. Agentbox is the agency system of record and the portal uploader that pushes an agency's for-sale and for-rent listings out to realestate.com.au, domain.com.au, allhomes and dozens of other Australian portals. A production API exists at api.agentboxcrm.com.au but is entirely closed: no developer portal, no published reference, no machine-readable contract, and access only after an integrator application is approved and per-office credentials are issued by support.

Generated by API Evangelist from https://raw.githubusercontent.com/api-evangelist/agentbox/refs/heads/main/apis.yml on 2026-07-26. This file is not published by the vendor.

## API

- [Agentbox API](https://www.agentbox.com.au/integrator-application): Production REST API for approved integration partners - contacts, listings, properties, staff, offices, inspections and notes. Base URL https://api.agentboxcrm.com.au. Authenticated with an X-API-Key header plus an X-Client-ID, behind a Tyk gateway. No public reference exists.

## Access

- [Integrator Application](https://www.agentbox.com.au/integrator-application): The access gate. All third parties wanting to integrate must complete this application and be reviewed by Reapit before an integration is approved.
- Credentials: an agency customer emails Reapit | Agentbox support (salessupportanz@reapit.com) to be issued an API Key, Client ID and Office ID scoped to its own office. There is no self-serve signup, no sandbox and no published key-issuance flow.

## Not available

- No OpenAPI, Swagger, GraphQL, AsyncAPI or OData contract - every candidate path on the API host returns the gateway's HTTP 401.
- No developer portal or docs subdomain: developer.agentbox.com.au, developers.agentbox.com.au and docs.agentbox.com.au do not resolve.
- No MCP server, no agent skills, no Postman collection, no CLI, no sandbox, no webhook or event documentation.
- No status page for Agentbox, no SLA, no deprecation policy, no security.txt, no bug bounty and no trust centre.
